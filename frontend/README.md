# CoffeeChain Frontend

Frontend React moderno para o sistema CoffeeChain - rastreabilidade de café com blockchain.

## 🚀 Tecnologias

- **React 18** - Framework UI
- **TypeScript** - Type safety
- **Vite** - Build tool ultrarrápido
- **Framer Motion** - Animações fluidas
- **React Router** - Roteamento
- **Lucide React** - Ícones modernos

## 🎨 Design

- Paleta de cores inspirada em café
- Fonte estilo Apple (SF Pro Display)
- Animações suaves e minimalistas
- Totalmente responsivo

## 📦 Instalação

```bash
npm install
```

## 🛠️ Desenvolvimento

```bash
npm run dev
```

Acesse: http://localhost:3000

## 🏗️ Build

```bash
npm run build
```

## 🐳 Docker

```bash
docker build -t coffeechain-frontend .
docker run -p 80:80 coffeechain-frontend
```

## 📱 Páginas

- **Home** - Apresentação do sistema
- **Rastrear** - Buscar café por código
- **Produtor** - Portal para produtores
- **Histórico** - Transações blockchain
